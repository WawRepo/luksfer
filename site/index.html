Luksfer

A file explorer for macOS that works like Windows Explorer. Enter opens, F2 renames, right-click makes a new file, and cut and paste moves files.

Download How to install Source code

Free and open source (MIT). Apple Silicon, macOS 15 or newer.

"Luksfer" is Polish for a glass block, the brick that lets light through a wall. It started as one person's fix after three decades on Windows: everything on the Mac was fine except Finder. It does a small set of things and does not try to do more.

Details view everywhere

Name, Date modified, Type and Size in every folder. Folders sort first, like Explorer.

One or two panes

Drag and drop between them. Tab moves to the other pane.

A path you can type

Click a part of the path, or type or paste a path. Type term for a terminal.

New file on right-click

New folder and New text file on every right-click menu.

Windows keys

Enter opens, F2 renames, ⌘X ⌘C ⌘V cut, copy and paste files.

A terminal inside

A panel at the bottom that follows the folder you are in.

What it does

  • Details view by default, in every folder: Name, Date modified, Type, Size.
  • One or two panes, with drag and drop between them.
  • A path bar you can click or type into, with folder autocomplete.
  • A search box that filters the folder as you type. Enter also searches the subfolders.
  • Favorites in the sidebar: drag a folder in to pin it, drag to reorder, right-click to unpin.
  • New folder and New text file on every right-click. Compress to zip, and Extract for zip, 7z and tar files.
  • Windows keys. The back and forward buttons of a mouse work too.
  • Delete moves to the Trash. Every file action can be undone, or asks first.
  • A terminal panel in the window, and "Open in Terminal App" for Terminal, iTerm2, Ghostty or Warp.
  • Network drives (SMB), like Explorer's "Map network drive". Passwords stay in the macOS Keychain.
  • A new window from any app with ⌥⌘Space, like Win+E.

The guide explains each of these. The keys page lists every shortcut.

Install

  1. Download Luksfer-<version>.dmg from the latest release.
  2. Open it and drag Luksfer to Applications.
  3. Open Luksfer. The app is not notarized by Apple, so macOS blocks the first open and shows "Luksfer" Not Opened. Click Done, not Move to Trash.
  4. Quit System Settings if it is open, then open it again. Go to Privacy & Security and scroll down to Security.
  5. Click Open Anyway under "Allow applications from" and confirm with your password or Touch ID. You do this only once per version.

If Open Anyway does not appear, run this line in Terminal. It removes the quarantine flag (the mark that makes macOS block a downloaded app) from Luksfer only, then opens the app. Run it only on a copy you trust. The check below shows that GitHub built your copy.

xattr -dr com.apple.quarantine /Applications/Luksfer.app && open /Applications/Luksfer.app

If you replace an older version that you keep in the Dock, the Dock icon can still point to the old copy in the Trash. Remove that icon from the Dock, open the new app, then right-click its icon and choose Options > Keep in Dock.

Check that GitHub built your copy

Each release has an attestation: a signed record of the repo, commit and workflow that built the disk image. Check it with the GitHub CLI:

gh attestation verify Luksfer-<version>.dmg --repo WawRepo/luksfer

A copy that someone changed fails this check.

Privacy

  • No network requests, no telemetry, no account. The one exception is a network drive that you set up: macOS makes that connection.
  • Listing a cloud folder (Google Drive and other File Provider folders) never downloads a file. Luksfer reads names, sizes and dates only, and draws icons from the file type.
  • Luksfer keeps its own settings in ~/Library/Application Support/Luksfer/. It never changes Finder's settings or Finder's sidebar.
  • This site has no cookies, no analytics and no files from other sites.

Something missing?

Luksfer stays small on purpose. If you need more, open an issue or fork it.
