FAQ

Install

Why does macOS block Luksfer the first time I open it?

Apple did not notarize Luksfer. Notarization is Apple's check of apps from outside the App Store. macOS blocks the first open of an app without it. You allow Luksfer once per version in System Settings > Privacy & Security > Open Anyway. The install steps show each click.

How do I know the download is the real one?

Each release has a GitHub attestation: a signed record of the repo, commit and workflow that built the disk image. Run gh attestation verify Luksfer-<version>.dmg --repo WawRepo/luksfer. A changed copy fails. The source code is on GitHub, so you can also build it yourself.

Does it work on an Intel Mac, or an older macOS?

No. Luksfer needs a Mac with Apple Silicon and macOS 15 or newer.

Why is it not on the Mac App Store?

App Store apps must run in Apple's sandbox, which lets an app open only the files you pick. A file explorer has to see all your folders, so the sandbox does not fit.

How do I update?

Download the new disk image and drag Luksfer to Applications again. Choose Replace. If you keep Luksfer in the Dock, remove the old icon and add the new app again, because the old icon can point to the copy in the Trash.

How do I remove Luksfer?
  1. In Settings, turn off "Open Luksfer at login".
  2. Quit Luksfer and move /Applications/Luksfer.app to the Trash.
  3. To remove the settings too, delete ~/Library/Application Support/Luksfer/.
  4. To remove saved network drive passwords, open Keychain Access, search for io.github.wawrepo.luksfer.network-drive and delete those items.

Privacy and safety

Does Luksfer send anything over the internet?

No. Luksfer makes no network requests, has no telemetry and needs no account. The one exception is a network drive that you add yourself: macOS makes that connection.

Will it download my Google Drive or iCloud files?

No. For cloud folders, Luksfer reads names, sizes and dates only, and draws icons from the file type. Listing and searching never start a download.

Does Luksfer change Finder?

No. Luksfer keeps its own settings in ~/Library/Application Support/Luksfer/. It never changes Finder's settings or Finder's sidebar. Finder still runs the desktop and the Dock, and "Show in Finder" in other apps still opens Finder.

Can I lose a file by mistake?

Delete moves files to the Trash. Delete Immediately asks first. Rename, move, copy, new items, Trash and Extract can be undone with ⌘Z. When a name is taken, Luksfer asks before it replaces anything.

Network drives

Why does macOS ask for my Mac password when I connect a drive?

Luksfer keeps the drive's password in your login keychain. macOS asks for your Mac password before it lets Luksfer read it. Click Always Allow so it does not ask every time. This keychain question takes your Mac password, not Touch ID.

A new version of Luksfer can make macOS ask once more. The app is not signed with an Apple developer certificate, so macOS sees each version as a new app.

Which kinds of network drives work?

SMB only: a NAS, a Windows shared folder, or a shared folder on another Mac. The address looks like smb://server/share or \\server\share.

Features

Why are there no tabs?

Two panes and more windows (⌘N, or ⌥⌘Space from any app) do the same job with less to learn.

Why is there no preview pane?

Space opens Quick Look, the macOS preview, for any file.

Can it rename many files at once?

No. A script or an AI agent in the terminal panel does that better. Press ⌃` to open a terminal in the folder.

Which archives can it extract?

.zip, .7z, .tar, .tar.gz, .tgz, .tar.bz2, .tbz2, .tar.xz and .txz. Not RAR, and not archives with a password. Compress makes zip files.

The ⌥⌘Space key does nothing. Why?
  • Luksfer must be running. Turn on Settings > "Open Luksfer at login" so it always is.
  • macOS uses the same key for the Finder search window. Turn that off in System Settings > Keyboard > Keyboard Shortcuts… > Spotlight > "Show Finder search window".
  • Check that Settings > "⌥⌘Space opens a new window in Downloads" is on.
I need a feature that is not here.

Luksfer stays small on purpose. Open an issue to ask, or fork the code and add it.
