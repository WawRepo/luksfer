Windows and panes

  • A window has one or two panes. Switch with the toolbar button, ⌥⌘1 or ⌥⌘2.
  • Each pane has its own folder, history, selection, sort and search.
  • Tab moves to the other pane. The active pane has a clear mark.
  • Open in Other Pane is on a folder's right-click menu. Swap Panes is ⌥⌘U, and Same Folder in Both is ⌥⌘=.
  • ⌘N opens another window. Luksfer remembers its windows, panes and folders when you quit and open it again.

Every folder opens in the details view: Name, Date modified, Type and Size. Right-click a column header to show Date created or Extension. Drag a column to move it, or drag its edge to resize it. Click a header to sort. Like Explorer, folders come first in an ascending sort.

Hidden files are off at first. ⇧⌘. shows them, and Luksfer remembers the choice. Space opens Quick Look, the macOS preview.

Moving around

  • Enter opens the selected file or folder.
  • Back and forward: the toolbar buttons, ⌘[ and ⌘], Backspace, or the back and forward buttons of a mouse. The mouse buttons work on the pane under the pointer.
  • ⌘↑ goes up one folder.
  • Type the first letters of a name to jump to it.
  • The Go menu has Home, Desktop, Documents, Downloads and Applications.

The path bar

  • Click a part of the path to go there. Click the › after a part to list its subfolders.
  • Click the empty end of the bar, or press ⌘L, to type a path. The whole path is selected, so you can paste over it.
  • It takes ~, full paths, relative paths, and paths copied from a terminal, with quotes or \ escapes. A path to a file opens its folder and selects the file.
  • Folder names complete as you type. Tab completes, Enter goes, Esc cancels.
  • Type term, terminal or cmd to open the terminal in this folder.
  • ⌥⌘C copies the path of the selected item, or of the folder.

Search

  • ⌘F goes to the pane's search box. The list shows only the names that match as you type.
  • Enter also searches the subfolders. Results come in as Luksfer finds them, with a Folder column that says where each one is. Every file action works on them.
  • Stop ends the search and keeps the results. Esc, Back or new text returns to the folder.
  • "Open Containing Folder" on a result's right-click menu goes to its folder.

Search matches names only, and stops at 20,000 results. It does not follow links, look inside apps, or go into another disk or network drive. It never opens a cloud folder whose contents are only online, so it never starts a download. The status bar counts the folders it skipped.

Favorites and the sidebar

  • Favorites: drag a folder onto Favorites to pin it, or use Pin to Favorites (⌃⌘T). Drag to reorder. Right-click to unpin, or choose Rename Label… to change the name. The path stays the same.
  • This Mac: Home, Desktop, Documents, Downloads, Pictures, and cloud folders such as Google Drive.
  • Locations: the start disk, Applications, external drives (with Eject), and the Trash.
  • Network: your saved network drives, then network volumes that you connected some other way.

Sections fold open and closed, and Luksfer remembers which ones you folded. ⌃⌘S hides or shows the sidebar.

Working with files

New files and folders

Right-click a file or empty space for New Folder and New Text File. Empty space also has New Markdown File. A folder's right-click menu has a New submenu that makes the item inside the folder or next to it. The new item starts with its name selected, so you can type a name. Esc keeps the default name.

Keys: ⇧⌘N for a new folder, ⌥⌘N for a new text file.

Rename

F2 renames in place. On most Mac keyboards you press fn with F2. If you prefer the Finder way, the Finder keys setting makes Enter rename.

Cut, copy and paste

  • ⌘X, ⌘C and ⌘V cut, copy and paste files.
  • Copy and paste work both ways with Finder. Finder has no cut, so a cut in Luksfer that you paste in Finder becomes a copy.
  • ⌥⌘V (Move Here) moves what you copied, like Finder.

Drag and drop

Drag between panes, onto a folder row, onto Favorites (this pins the folder), and to and from other apps. On the same disk a drag moves; to another disk it copies. Hold ⌥ to copy or ⌘ to move. A badge shows what will happen.

When a name is taken

Luksfer asks: Replace, Skip or Keep Both. It shows the size and date of both items. When more items follow, "Do this for all" answers for the rest. Stop (Esc) ends the action.

Trash and Undo

  • ⌘⌫ moves to the Trash. Delete Immediately (⌥⌘⌫) skips the Trash, and asks first.
  • ⌘Z undoes rename, move, copy, new item, Trash and Extract. One Undo undoes one action.
  • After an action, the status bar says what happened, with an Undo button.
  • Long copies show progress in the status bar. You can stop them, and the window keeps working.

Compress and Extract

Compress on the right-click menu makes a zip file of the selected items.

Extract is on the right-click menu of an archive, and in the File menu. It knows these endings: .zip, .7z, .tar, .tar.gz, .tgz, .tar.bz2, .tbz2, .tar.xz and .txz. It uses the tools that come with macOS.

  • What is in the archive comes out next to it. The archive stays.
  • One item at the top comes out as itself. Several come out in a folder named after the archive: photos.tar.gz gives a folder photos.
  • A taken name gets a number, such as Report (2). Nothing is overwritten.
  • If the extract fails, nothing is left behind. ⌘Z moves what came out to the Trash.
  • An archive from the internet keeps the macOS download mark on what comes out, so macOS still checks those files.
  • An archive with a password shows an error. RAR files get no Extract.

The terminal

  • ⌃` opens and closes a terminal panel at the bottom of the window. It runs your login shell (zsh) in the active pane's folder.
  • Follow (on at first): cd in the terminal moves the active pane, and opening a folder moves the shell. This happens only while the shell waits at its prompt, not while a command runs.
  • Open in Terminal App (⌥⌘T) opens Terminal, iTerm2, Ghostty or Warp in the folder. Settings picks the app.
  • Programs that print text in the panel cannot read or change your clipboard.

Network drives

Like Explorer's "Map network drive". Luksfer supports SMB drives, such as a NAS or a shared folder on another computer.

  1. Click the + next to Network in the sidebar, or press ⌘K.
  2. Type the address: smb://server/share or \\server\share.
  3. Give it a name. Type your user name, or leave it empty for guest access, and the password.
  • Click the drive to connect. It opens in the active pane. A connected drive has an Eject button that disconnects it.
  • Right-click a drive for Connect, Open in Other Pane, Disconnect, Edit and Remove from Sidebar.
  • The password goes into the macOS Keychain only, never into Luksfer's settings file. Luksfer never shows a saved password again. Edit can only replace it.
  • macOS makes the connection. It runs in the background, and the Stop button ends it.

A new window from any app

Press ⌥⌘Space in any app, Luksfer included, to open a new single-pane window in Downloads, like Win+E on Windows.

  • Luksfer has to be running for the key to work. It keeps running when you close its last window. To start it when you log in, turn on Settings > "Open Luksfer at login".
  • macOS uses ⌥⌘Space for the Finder search window. Turn that off first: System Settings > Keyboard > Keyboard Shortcuts… > Spotlight > "Show Finder search window".
  • To turn the key off, use Settings > "⌥⌘Space opens a new window in Downloads". Luksfer then quits when you close its last window.
